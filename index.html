    Commands

    • look around — reprints the current room description
    • go <direction> — move (north, south, east, west, north east ...)
    • jump — jump, you might find a secret
    • bag — show inventory
    • search — search the current room for items
    • examine — examine the current room more closely
    • poke — poke things in the current room, use with caution
    • take/drop/use <item> — pick up/drop/use an item
    • give <item> to <npc> — give an item
    • talk to <npc> — talk to an NPC
    • ask <npc> for help — get a hint from an NPC
    • build <item> — build in the workshop (cart, birdhouse, shelf)
    • place <item> — place workshop items to solve puzzles
